🎯 Why Logistic Regression Wins

✅ Better Balanced Performance
LR handles both Positive and Negative classes more evenly, unlike NB which over-predicts Positive.
✅ Higher Negative Recall
77% vs 66% — LR correctly identifies 77% of negative reviews, critical for complaint detection.
✅ Stable Cross-Validation
5-fold CV: 79.4% ± 2.1% — consistent performance across different data splits.
⚠️ Limitation: Neutral Class
Both models struggle with Neutral (only 5.4% of data). SMOTE oversampling recommended.

Key Findings & Recommendations

📈

Majority Satisfaction

56.5% of reviews are Positive (avg. 4.94★), showing that Grab users are broadly satisfied. This is a strong foundation but the 38.1% Negative rate demands attention.

🚗

Driver Cancellations = #1 Issue

"Driver" + "cancel" appear across both Negative topics and the general topic. Implementing cancellation penalties and better driver vetting is crucial.

🍔

Food Delivery is a Strength

Topic 3 (Food Delivery Praise) uses highly positive vocabulary: "convenient", "fast", "easy". Grab should leverage and market this service more aggressively.

💳

Payment Issues Are a Pain Point

"Wallet" and "money" appear prominently in Negative topics. Grab Wallet reliability is a significant dissatisfier — improving it could shift neutral/negative users to positive.

✍️

Negative Reviews Are Longer

Users write more when dissatisfied — Negative reviews average more words than Positive ones. This provides richer data for complaint analysis and root-cause identification.

🤖

Model Can Automate Triaging

With 79.2% accuracy, Logistic Regression can automatically label incoming reviews, enabling real-time sentiment monitoring and faster response to negative feedback spikes.

🌐

Multilingual Challenge

Malay/Bahasa terms ("tidak", "saya", "bisa", "yang") appear in negative topics, indicating a significant segment of non-English reviewers whose feedback needs separate NLP treatment.

🎯

Answer to Research Question

YES — the analysis successfully identifies sentiment patterns and themes. Users are satisfied with delivery but unhappy with drivers and payments. Both objectives from Part 1 are fulfilled.

🔧 Recommended Improvements for Future Work

BERT / RoBERTa
Context-aware embeddings would improve accuracy especially for short/ambiguous reviews and sarcasm detection.
SMOTE Oversampling
Address the Neutral class imbalance (only 5.4%) using synthetic minority oversampling to improve its classification.
Multilingual NLP
Use multilingual BERT or Malay-specific models to properly handle Bahasa Malaysia/Indonesia reviews.
Temporal Analysis
Track sentiment trends over time (monthly) to correlate with Grab service updates, pricing changes, or external events.
